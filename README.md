# 🕵️ Smart Fake Review Detector

An AI-powered web application that detects whether a product review is **Real or Fake** using Machine Learning and Natural Language Processing (NLP).

---

## 🚀 Features

* 🔍 Real-time review classification
* 🧠 Hybrid AI system (Machine Learning + Rule-based logic)
* 🎯 Smart confidence scoring system
* 📊 Interactive dashboard with charts
* 🔍 Explainable AI (why a review is fake or real)

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn
* Pandas
* Joblib

---

## ▶️ How to Run Locally

1. Install dependencies:

```
pip install -r requirements.txt
```

2. Run the app:

```
streamlit run app.py
```

---



---

## 📁 Dataset

Dataset is not included due to large file size.

You can use your own dataset or place it inside the `data/` folder.

---

## 🧠 Model

The model is trained using:

* TF-IDF Vectorization
* Logistic Regression

To retrain the model:

```
python train_model.py
```
